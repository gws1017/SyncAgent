## ~~장비 자동합성 / 보관함 확장 - 보상형 광고~~ (구현 완료: 2026-07-24)

코드 구현 완료(game.h/cpp, equipment.h/cpp, dashboard.cpp, main_android.cpp,
MainActivity.kt, AdMob SDK 연동). **단, 지금은 구글 공개 테스트 광고 단위
ID를 쓰고 있어서 실제 광고 수익은 안 남** — 실제 출시 전에 AdMob 콘솔에서
계정 만들고 진짜 앱 ID/광고 단위 ID를 발급받아 `AndroidManifest.xml`,
`MainActivity.kt`의 테스트 ID를 교체해야 함. 아래는 설계 당시 기록(구현과
세부 수치 일치, 참고용으로 보존).

### 문제
합성(TabEquipment)이 "같은 등급 3개 → 상위 등급 1개, 실패 시 1개 반환" 구조라,
재료가 쌓일 때마다 등급별로 여러 번 수동으로 눌러야 함. 특히 일반(100% 성공)
등급은 그냥 반복 노가다일 뿐이라 자동화해도 밸런스에 영향이 없음.

### 제안 (시간제 버프, 2026-07-24 수정)
처음엔 "광고 한 번 = 그 순간 쌓인 재료 일괄 합성" 일회성으로 설계했는데,
이 게임 자체가 방치형(틱마다 알아서 진행)이라 오히려 **"광고 한 번 보면
일정 시간 동안 자동합성이 알아서 계속 돌아간다"** 는 시간제 버프 쪽이 게임
컨셉과 더 잘 맞음. 방치형 특성상 유저가 자리를 비우는 시간 단위(체감상
몇 시간)를 커버해야 실제로 쓸모가 있어서, 처음 제안한 30분은 너무 짧다고
판단 — **3시간**으로 조정.

장비탭에 **"광고 보고 자동합성 켜기 (3시간)"** 버튼 추가. 시청 완료 시 그
순간부터 3시간 동안, 매 틱마다 (일반→희귀→영웅 순으로) 재료 3개가 모일 때마다
자동으로 합성이 실행됨. 버프가 켜져 있는 동안은 화면에 남은 시간 표시.
성공률/결과는 수동 합성과 완전히 동일(변경 없음) — 확률 자체를 건드리는 게
아니라 "매번 손으로 안 눌러도 되게" 해주는 편의 기능.

### 플랫폼별 획득 — 모바일 전용 (PC는 골드 대체 불가, 2026-07-24 결론)
처음엔 "PC는 스토어 정책이 없으니 광고 없이 무료로 주자"고 생각했는데, 이
게임은 PC ↔ 모바일이 같은 세이브를 Firebase로 동기화하는 구조라 그러면
PC에서 공짜로 얻은 버프/확장이 그대로 모바일 계정에도 넘어가버려서 모바일
광고 자체가 무의미해짐 — 아이콘/프라이버시 기본값처럼 로컬 전용 설정이
아니라 세이브에 저장되는 상태라 이 문제가 생김.

대안으로 "PC는 광고 대신 골드 소모"도 검토했지만 기각 — 골드는 그냥 플레이하면
공짜로 벌리는 자원이라 광고(실질적으로 현금 가치)와 등가교환이 아님. PC에서
직접 광고 SDK를 붙이는 것도 검토했으나(웹뷰 기반 웹 광고 등) 표준 SDK가 없고
서버 시청 검증 인프라도 없어서 모바일 대비 작업량이 훨씬 큼.

**결론**: 이 기능은 **모바일에서만 획득 가능**. PC엔 획득 버튼 자체가 없음.
다만 모바일에서 정당하게 광고 보고 얻은 버프/확장 상태는 세이브 동기화를 통해
PC에서도 정상적으로 누릴 수 있음(이건 문제 없음 — 이미 대가를 치른 혜택이
다른 기기로 넘어가는 것뿐).

### 세부 규칙 (초안)
- **지속시간**: 광고 1회 시청 = 3시간 자동합성 버프. 버프 중 재시청하면 그냥
  잔여시간 리필(연장 아님, 3시간으로 리셋) — 스택으로 무한정 늘어나는 건 방지.
- **동작 시점**: 버프가 켜져 있는 동안 `GameTick`마다 (수동 합성과 같은 함수
  재사용해서) 등급 낮은 순으로 재료 3개 이상이면 자동 실행. 결과물은 그 즉시
  재료로 편입되지 않음(연쇄 합성으로 전설 남발 방지 — 다음 틱에 다시 판단).
- **보관함 공간**: 가득 차면 그 틱은 조용히 건너뜀(에러/알림 없음, 공간 생기면
  다음 틱에 재개).
- **획득 경로**: 안드로이드 전용, "광고 보고 자동합성 켜기" 버튼. PC엔 이
  버튼이 아예 없음(위 결론 참고).
- **결과 알림**: 낱개 알림은 도배되니 안 띄우고, 대시보드 "최근 이벤트"에만
  합성 발생 시 조용히 기록(1.1.0에서 고친 "가방 가득 참" 반복 알림 문제와
  같은 함정이니 낱개 토스트는 피할 것).

### 확인/논의 필요한 점
- 안드로이드 AdMob(또는 다른 리워드 광고 SDK) 연동 필요 — 현재 프로젝트에
  광고 SDK가 전혀 붙어있지 않음(문서상 문구만 준비돼 있음), 신규 의존성 추가
  작업이 꽤 큼
- 버프 잔여시간을 세이브에 저장할지(껐다 켜도 유지) 말지(재실행 시 초기화)
- 3시간이라는 구체적 수치가 실제 파밍 사이클(스테이지 40+ 기준)과 맞는지는
  실사용 데이터 없이는 추정만 가능 — 배포 후 조정 여지 있음

## 장비 보관함 확장 - 보상형 광고 (설계: 2026-07-24, 모바일 전용)

자동합성과 같은 날 논의된 아이디어 — 자동합성이 "쌓인 재료를 빨리 처리"라면
보관함 확장은 "그동안 안 넘치게 버티는 여유"라 상호보완적.

- 지금 보관함은 20칸 고정(`Inventory::MAX_ITEMS`)
- 광고 시청 시 **영구로 +2칸** 추가(시간제 아님 — 칸 부족은 "지금 당장"의
  문제라 영구 확장이 더 자연스러움)
- 남발 방지로 **횟수 제한**: 예를 들어 최대 5회(+10칸, 최종 30칸)까지만
  확장 가능, 그 이상은 막힘
- **모바일 전용** — 자동합성과 같은 이유(세이브 동기화로 PC 무임승차 방지)로
  PC엔 획득 버튼 없음. 모바일에서 얻은 확장은 세이브 동기화로 PC에서도 정상
  적용됨.

### 확인/논의 필요한 점
- 확장 횟수 상한(5회/+10칸)이 적당한지 — 장비 파밍 페이스 감안한 재검토 필요
- 자동합성 버프와 마찬가지로 안드로이드 광고 SDK 신규 연동 필요(같은 작업
  안에서 같이 처리하는 게 효율적)
