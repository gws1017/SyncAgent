# 시스템 기획서 (1.1.0 기준)

현재 코드에 실제로 구현되어 있는 수치/규칙을 그대로 정리한 문서. 기획 아이디어가
아니라 "지금 게임이 실제로 이렇게 동작한다"는 스냅샷이며, 2차 특성 디버프
설계(`design_backlog.md` #1) 등 다음 작업의 기준선으로 쓴다.

틱 주기: 5초(PC 기준 `TICK_MS`). 아래 수치는 모두 "틱 1회당" 값이다.

---

## 1. 클래스

계정당 영웅 슬롯 3개(로스터), 클래스당 정확히 1명. 클래스는 최초 생성 후 변경 불가
(프레스티지해도 클래스 유지).

### 전사 (Warrior)
- 컨셉: 단단하고 안정적인 근접 전투
- 기본 공격력 배율: x1.5 (`totalDmg = baseAtk * 1.5`)
- 보스 스테이지: 데미지 x2.0 추가 + 처단자 특성 보너스
- 골드 획득 x1.2

### 마법사 (Mage)
- 컨셉: 강력하지만 불안정한 원거리 마법
- 기본 공격 x0.7 (폭발 실패 시)
- 폭발(크리티컬) 확률 기본 20%, 발동 시 x4.0 데미지
- XP 획득 x1.5

### 도적 (Rogue)
- 컨셉: 빠르고 날쌘 근접 약탈
- 매 틱 기본 2회 공격 (`totalDmg = baseAtk * 2`)
- 아이템 드랍률 x2.0
- 골드 획득 x1.3

## 2. 스탯 성장 공식 (레벨/스테이지 무관, 공용)

| 항목 | 공식 | 비고 |
|---|---|---|
| 플레이어 기본 공격력 | `10 + stage * 0.9` | 몹 방어력 성장(1.8/stage)의 절반 속도 |
| 플레이어 기본 방어력 | `10 + stage * 0.75` | 몹 공격력 성장(1.5/stage)의 절반 속도 |
| 플레이어 기본 최대체력 | `350 + stage * 8` | 초반 생존력 확보를 위해 200→350 상향(1.1.0) |
| 몹 체력 | `30 * 1.18^(stage-1)`, 보스는 x5 | 지수 성장 |
| 몹 방어력 | `5 + stage * 1.8` | 이걸 못 넘으면 데미지 0 (진짜 진행 정지 조건) |
| 몹 공격력 | `4 + stage * 1.5` | |
| 방어 시 피해 감소 | `reduction = def / (def + 50)` (비율 감소, 0%~100% 점근) | 아무리 투자해도 완전 무적은 안 됨 |

경험치 곡선: `XpForLevel(level) = 50 * 1.25^level` (1.1.0에서 1.30→1.25로 완화).
레벨업마다 XP 요구치를 그만큼 지수적으로 더 필요로 하게 됨.

틱당 XP/골드 획득: `xpGain = (5 + level*2) * xpMult`, `goldGain = (3 + level) * goldMult`
(각 배율에 업그레이드/계승/클래스/장비 보너스가 곱·합산으로 반영됨, 아래 4장 참고).

---

## 3. 업그레이드 (골드 소비, 레벨 무관 상시 구매)

레벨당 4종, 각각 최대 10레벨. 비용은 `baseCost * 2^level` (레벨마다 2배).

| 업그레이드 | 효과 | 레벨당 | 기본 비용 |
|---|---|---|---|
| 수련 강도 (XP) | XP 획득량 +20%/레벨 | 최대 +200% | 50G |
| 채집 효율 (Gold) | 골드 획득량 +20%/레벨 | 최대 +200% | 80G |
| 탐색 본능 (Drop) | 드랍률 +10%/레벨 | 최대 +100% | 120G |
| 전투 본능 (Atk) | 공격력 +15%/레벨 | 최대 +150% | 100G |

## 4. 특성 (클래스별 슬롯 6개 = 1차 3개 + 2차 3개)

- 1차(슬롯 0~2): 레벨업마다 1포인트 지급, 평생 캡 **15포인트** (3개 풀업엔 30 필요 → 항상 일부만 선택).
- 2차(슬롯 3~5): **레벨 25**부터 해금, 별도 포인트 풀, 마찬가지로 평생 캡 **15포인트**.
- 각 특성 슬롯 최대 10레벨.
- 1.1.0에서 2차 계수를 1차와 동일하게 맞춤(체력 보너스만 2차 고유 혜택으로 유지) — "2차 투자가 손해"라는 피드백 대응.

2차 특성(TAL_3~5)은 이름 컨셉에 맞는 디버프를 하나씩 끼워 넣은 트레이드오프형으로
재설계됨(1.1.0 이후) — 순수 상시 버프였던 이전 버전과 달리, 대부분 "버프 + 그보다
작은 디버프" 조합이거나 조건부/확률 발동형이다.

### 전사 — 탱커형
| 슬롯 | 이름 | 효과/포인트 | 차수 |
|---|---|---|---|
| 0 | 철벽 방어 (패시브) | 방어력 +10% | 1차 |
| 1 | 전장의 분노 (패시브) | 공격력 +8% | 1차 |
| 2 | 처단자 (패시브) | 보스 데미지 +15% | 1차 |
| 3 | 불굴의 의지 (조건부) | **체력 50% 이하일 때만** 방어력 +15% | 2차 |
| 4 | 광전사 (패시브) | 공격력 +10% / **받는 피해 +5%(디버프)** | 2차 |
| 5 | 수호자 (패시브) | 방어력 +10% / **공격속도 -3%(디버프)** | 2차 |

불굴의 의지는 평소엔 무효과이고 위기 상황(HP 50% 이하)에서만 발동하는 "버티기" 특성이라
디버프가 따로 없음. 광전사/수호자는 버프가 1차 대응 슬롯보다 크되(+10% vs +8%) 그만큼
디버프를 감수해야 함.

### 마법사 — 폭딜 + 자가회복형
| 슬롯 | 이름 | 효과/포인트 | 차수 |
|---|---|---|---|
| 0 | 마나 증폭 (패시브) | 폭발 데미지 +15% (배율 4.0 위에 가산) | 1차 |
| 1 | 마력 폭주 (패시브) | 폭발 확률 +2%p (기본 20%에 가산, 상한 100%) | 1차 |
| 2 | 마나 흡혈 (패시브) | 체력흡수 +3% | 1차 |
| 3 | 마나 코어 (패시브) | 폭발 확률 +3%p / **폭발 데미지 -3%(디버프)** | 2차 |
| 4 | 원소 폭발 (패시브) | 폭발 데미지 +20% / **평타 데미지 -5%(디버프)** | 2차 |
| 5 | 라이프 드레인 (패시브) | 체력흡수 +4% / **공격력 -3%(디버프)** | 2차 |

마나 코어는 "마나통이 커져서 더 자주 캐스팅하지만 한 번에 담기는 위력은 줄어드는" 저위력·고안정
빌드, 원소 폭발은 반대로 고위력·저안정("몰빵 폭딜") 빌드 — 서로 반대 방향의 트레이드오프.
라이프 드레인은 기존 "흡혼"에서 개명(무협풍 어감 제거).

### 도적 — 회피 + 다회타형
| 슬롯 | 이름 | 효과/포인트 | 차수 |
|---|---|---|---|
| 0 | 연속 공격 (패시브) | 공격속도 +10% | 1차 |
| 1 | 기습 (확률) | 추가 공격 확률 +4%p | 1차 |
| 2 | 은신 회피 (패시브) | 받는 피해 -5% | 1차 |
| 3 | 쾌속 (패시브) | 공격속도 +12% / **방어력 -3%(디버프)** | 2차 |
| 4 | 치명적 기습 (패시브) | **방어관통 +5%** / 회피율 -3%p(디버프) | 2차 |
| 5 | 소매치기 (확률) | 매 공격 성공 시 확률적으로 골드 획득, 실패 시 자기 체력 소량 피해 | 2차 |

치명적 기습은 기존 "추가 공격 확률"(1차 기습과 메커니즘이 중복)에서 **방어관통**으로 완전히
교체됨 — 지금까지 없던 새로운 스탯 타입. 소매치기도 기존 "야성"(받는 피해 감소)을 완전히
대체한 신규 확률형 특성:
- 성공 확률 = `5%p * 레벨` (최대 50%)
- 공격이 실제로 데미지를 입힌 틱마다 1회 판정
- 성공: 그 틱 골드 획득량의 +50% 추가 획득
- 실패: 최대체력의 2% 만큼 자기 체력 피해(반동)

쾌속과 치명적 기습은 둘 다 디버프가 있지만 종류가 겹치지 않음(방어력 vs 회피율).

## 5. 전투 로직 (틱마다 실행)

1. `atkMult = 1 + 장비공격력% + 계승% + 업그레이드(전투본능)% + 특성공격력%`
2. `baseAtk = PlayerBaseAtk(stage) * atkMult`
3. 클래스별 `totalDmg` 산출 (위 1장 공식)
4. `numAttacks = 1 + floor(atkSpeedBonus)` + (소수부 확률로 +1) → `totalDmg *= numAttacks`
5. 도적 "기습/치명적 기습" 확률 발동 시 "한 타 분량"(공속 배수 적용 전)만 추가로 더함
6. `totalDmg = max(0, totalDmg - 몹방어력)` — 방어력을 못 넘으면 0
7. 체력흡수: `heal = totalDmg * lifesteal%` (소수점 이월 누적, 정수 반영)
8. 몹 체력이 0 이하면 스테이지 클리어 → 골드/XP 보상, 다음 스테이지로, 체력 전부 회복
9. 몹 반격: `dmgToPlayer = MitigateDamage(몹공격력, 내방어력) * (1 - 회피%)`, 회피 상한 90%
10. 플레이어 체력 0 이하 → 전투(스테이지 진행도)만 리셋, 스테이지 자체는 유지, `deathCount` 증가

공격력(atkMult)과 공격속도(numAttacks)는 수학적으로 동치 — 둘 다 `totalDmg`(방어력 차감 전)에
곱해지는 선형 배율이라, 어느 쪽에 투자해도 최종 데미지 기여도는 동일함. 몹 방어력은 딱 한 번만
차감되므로 구성비와 무관.

## 6. 스테이지/드랍

- 5의 배수 스테이지는 보스(몹 체력 x5, 클리어 보상 x3)
- 스테이지 20부터 드랍 등급에 희귀(20%) 섞임
- 스테이지 40부터 영웅(5%) + 희귀(20%) 섞임 (전설은 합성 전용, 드랍 불가)
- 스테이지 **40**부터 프레스티지 해금 (`PRESTIGE_STAGE_REQ`)
- 드랍 확률: `dropChance% = 6 * dropMult` (클래스/업그레이드/장비/계승 보너스 반영)

---

## 7. 장비

등급 4단계: 일반 → 희귀 → 영웅 → 전설. 등급별 고정 보너스%:

| 등급 | 보너스 | 합성 재료(3개) → 결과 | 성공률 |
|---|---|---|---|
| 일반 | +5% | → 희귀 | 100% |
| 희귀 | +15% | → 영웅 | 70% (실패 시 희귀 1개 반환) |
| 영웅 | +30% | → 전설 | 40% (실패 시 영웅 1개 반환) |
| 전설 | +60% | 합성 불가(최종 등급) | - |

스탯 종류는 랜덤 배정(공격력/XP/골드/드랍률/방어력/체력흡수/공격속도 중 1개).
장착 슬롯 5개, 보관함 20칸.

- **리롤** (1.1.0): 영웅 등급 이상부터, 아이템당 평생 1회만 가능. 비용 `100 * 4^등급`(일반=100, 희귀=400, 영웅=1600, 전설=6400).
- **삭제** (1.1.0): 전설 등급 아이템만 가능(낮은 등급은 합성으로 자연 소모되므로 불필요). 확인창 없이 즉시 삭제.

## 8. 프레스티지 (계승)

- 스테이지 40 이상에서 가능
- 계승 보너스 획득량: `(업그레이드 레벨 합 + 특성 레벨 합 + 장착템 보너스%합) * 0.15`(%p)
- 계승 보너스는 계정 전체 공용 자원 — XP/골드/드랍률/최대체력/공격력/방어력 배율에 전부 가산됨(`legacyFrac = legacyBonusPct / 100`)
- 프레스티지 시 유지: 클래스, 장착 장비, 이 영웅의 프레스티지 횟수(+1)
- 리셋: 레벨/XP/골드/업그레이드/특성/보관함/스테이지 전부 초기화

## 9. 참고

- `legacyBonusPct`는 필드명이 "Pct"이지만 실제로는 %p 단위 누적값이며 사용 시 항상 `/100`
  해야 함 — 1.1.0 이전 버그의 근본 원인이었으니 새 코드에서 반복하지 말 것.
- 2차 특성 디버프로 인해 `atkSpeedBonus`/`evasionBonus`/`defenseBonus`/`critDmgBonus` 등
  일부 보너스 필드가 음수가 될 수 있음 — 사용하는 곳마다 배율이 뒤집히지 않게 클램프 처리됨
  (`game.cpp`의 `GameTick` 참고). 새 특성 추가 시 이 패턴 유지할 것.
