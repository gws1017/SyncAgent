## 장비 자동합성 - 보상형 광고 (설계: 2026-07-24)

### 문제
합성(TabEquipment)이 "같은 등급 3개 → 상위 등급 1개, 실패 시 1개 반환" 구조라,
재료가 쌓일 때마다 등급별로 여러 번 수동으로 눌러야 함. 특히 일반(100% 성공)
등급은 그냥 반복 노가다일 뿐이라 자동화해도 밸런스에 영향이 없음.

### 제안
장비탭 합성 섹션에 **"광고 보고 자동합성"** 버튼 추가. 시청 완료 시, 지금
가능한 합성을 등급 낮은 순(일반→희귀→영웅)으로 재료가 3개 미만이 될 때까지
반복 실행. 성공률/결과는 수동 합성과 완전히 동일(변경 없음) — 그냥 "여러 번
누르는 걸 한 번에" 해주는 UX 단축 기능이지 확률 자체를 건드리는 건 아님.

### 세부 규칙 (초안)
- **반복 순서**: 일반 → 희귀 → 영웅 순으로, 각 등급에서 재료 3개 이상 남는 한
  계속 반복. 크래프트 결과(희귀/영웅/전설)가 다시 재료로 즉시 편입되진 않음
  (같은 실행 내에서 방금 나온 결과물을 또 합성하진 않음 — 무한 연쇄합성으로
  전설이 남발되는 것 방지).
- **보관함 공간**: 보관함이 가득 차면 그 시점에서 자동합성 중단(에러 없이
  조용히 멈춤, 남은 결과는 다음 실행 때).
- **PC**: 스토어 광고 정책/SDK가 없는 사이드로드 배포라 광고 없이 그냥
  무료로 제공(버튼 이름도 "자동합성"으로, 안드로이드만 "광고 보고 자동합성").
  1.1.0에서 "PC는 정책 제약 없음" 원칙과 동일선상.
- **쿨다운**: 광고 UX 피로 감안, 완전 무제한 대신 재시청 간격을 둘지 검토
  필요(예: 30분 쿨다운 vs 무제한이지만 매번 광고). 결정 보류.
- **결과 요약**: "자동합성 완료 — 성공 N개 / 실패 M개" 식으로 이벤트 로그 1줄
  요약(각 결과를 낱개로 다 띄우면 알림 도배됨, 1.1.0에서 고친 "가방 가득 참"
  반복 알림 문제와 같은 함정이니 주의).

### 확인/논의 필요한 점
- 안드로이드 AdMob(또는 다른 리워드 광고 SDK) 연동 필요 — 현재 프로젝트에
  광고 SDK가 전혀 붙어있지 않음(문서상 문구만 준비돼 있음), 신규 의존성 추가
  작업이 꽤 큼
- 쿨다운 유무/주기
- "재료 3개 미만까지 반복"이 스테이지 40+ 파밍량 기준으로 실제로 몇 회
  실행되는지 감(뻥튀기/과소평가 둘 다 체크 필요) — 실사용 데이터 없이는 추정만 가능

## 콘텐츠 확장 필요성 (제안: 2026-07-24)

진행 속도가 빨라지면(XP 곡선 완화 등) "게임을 다 했다"는 느낌이 더 빨리 올 수
있음 — 프레스티지 이후의 목표/콘텐츠를 늘리는 방향도 같이 고민 필요
(예: 추가 스테이지 구간, 새 장비 등급, 클래스별 추가 특성 슬롯 등).
